# Similar listings section on detail page for price reference

On the detail page, show a list of similar apartments in the same area as reference. Match on: same omrade, similar size (bra), similar room count, similar type. Show both active listings and recently sold ones with their prices.

Helps answer: is this apartment priced fairly compared to similar ones nearby? Could sort by similarity (closest match first).

Data is already available in `annonser` + `solgte` tables.
