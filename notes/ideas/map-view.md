# Map view with active and sold listings

Interactive map showing all tracked apartments. Active listings get one icon/color, sold (last 12 months) get another. Clicking an icon opens the listing detail.

## Prerequisites

- Need to scrape and store latitude/longitude coordinates for each listing (Finn may have this in the page source or via address geocoding)
- Map library options: Leaflet.js (free, uses OpenStreetMap) or similar
